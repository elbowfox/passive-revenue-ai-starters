# Telegram AI Bot with Stars Payments

## Monetization
- Free tier: 5 queries
- Paid: Telegram Stars packs (users buy Stars in Telegram)
- Alternatives: Subscriptions via Stripe + web app, or ads

## Setup
1. Create bot with @BotFather
2. pip install pyTelegramBotAPI python-dotenv
3. Copy .env.example to .env and add token
4. python bot.py
5. Deploy to Railway, Render, Fly.io, or VPS (free tiers available)

## AI Integration
Replace the placeholder with calls to OpenAI, Anthropic, Grok, or local models.
